# Contributing to PORTFOLIO

Thank you for your interest in contributing! As a personal portfolio, direct code contributions are generally not sought, but feedback and suggestions are always welcome.

## How to Contribute

1.  **Report Bugs:** If you find a bug, please open an issue on GitHub.
2.  **Suggest Features:** Have an idea to make this portfolio better? Open an issue!
3.  **Feedback:** Feel free to reach out via the contact form or email.

## Development Workflow

If you wish to run this project locally:

1.  Clone the repository: `git clone https://github.com/vincenzo-afk/PORTFOLIO.git`
2.  Open `index.html` in your browser.
3.  For the contact form, you will need to set up a Vercel environment with a `RESEND_API_KEY`.

## Code of Conduct

Please be respectful and professional in all interactions.
